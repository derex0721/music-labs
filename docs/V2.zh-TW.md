# Music Labs V2 測試版

V2 在獨立分支 `v2/audio-security` 開發。先驗收預覽版，再決定是否合併至 `main`；正式 V1 不受這次修改影響。

## 本次更新

- 升級 Vite、Wrangler、Cloudflare Vite 外掛、Workers 型別、Tailwind 與 vinext；React / React DOM / RSC 同步套用 19.2.8 安全修補。
- TypeScript ADSR 合成器：10ms Attack、150ms Decay、65% Sustain、250ms Release。提前放開琴鍵時保留當下音量再淡出；停止後回收節點。支援 MIDI noteOn/noteOff、參數調整、allNotesOff 與 dispose。
- Compressor 使用 3ms Attack、12:1 Ratio，配合音量餘裕降低破音風險。它不是能保證任何輸出都不超峰值的硬式限制器。
- Cloudflare Turnstile 進站驗證：伺服器核對 token、網域與用途後才發放一小時的簽章 Cookie。API 與網頁資源都受保護；設定缺漏不會自動放行。
- 測試版提供 noindex 回應標頭與 robots.txt。

## 啟用 Cloudflare 預覽

1. 在現有 Pages 專案允許 `v2/audio-security` 分支的 Preview 部署。建置指令為 `npm run build:pages`，輸出目錄為 `public`，Node 至少 22.13，建置時需安裝開發相依套件。
2. 建立 Turnstile 的 **Managed** 元件，允許實際預覽網址的 hostname。
3. 在 Pages 的 **Preview** 環境加入 `TURNSTILE_SITE_KEY`（公開 site key）、`TURNSTILE_SECRET_KEY`（加密秘密），以及 `VERIFICATION_SESSION_SECRET`（加密秘密，至少 32 字元的隨機值，可用 `openssl rand -hex 32` 產生）。
4. 重新部署該 Preview。不要把秘密貼到聊天室或提交至 GitHub，也先不要修改 Production 環境。

Cloudflare 自動提供的 `CF_PAGES_BRANCH` 只有等於 `main` 時才視為正式版；未提供時預設禁止索引。所有路徑都會執行 Pages Functions，正式啟用前請確認帳戶的用量配額。

## 驗收

執行 `npm run test:v2`、`npx tsc --noEmit`、`npm run build:pages` 與 `npm run build`。單元測試使用模擬 AudioNode 與 Siteverify，並不等同實際聽感或真人驗證端到端測試。

預覽金鑰設定後，用無痕視窗檢查進站驗證、成功後重新整理、錯誤重試、意見表單，以及和弦播放、快速重複按鍵、停止和弦進行與切換分頁。另請在手機 Safari / Chrome 確認音訊及版面。
